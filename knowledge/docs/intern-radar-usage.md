# 实习雷达使用说明

## 它解决什么问题

实习雷达自动采集你的工作数据（代码提交、内部任务系统的任务与工时日志、授权后的聊天摘要），
按天整理成结构化日报与今日计划，识别卡点并主动提醒，同时把导师经验沉淀成可检索的知识库，
供你在学习问答里直接问。

## 页面与角色

按角色分流的页面，左侧菜单只显示当前角色能进的入口。

**实习生可见**

- 我的今日：当日工作记录、今日计划、未处理的风险提醒，明细默认折叠，点开看证据
- 我的报告：日报、今日计划、周报列表与详情，可手动生成当日总结
- 学习问答：基于知识库的问答，先检索、再读文档、最后逐字作答，答复带文档编号引用
- 文档库：团队知识文档，列表只留摘要，点开抽屉看正文；登录用户都可以上传文档
- 会话绑定：绑定飞书会话用于采集聊天摘要，会话标识需要从飞书客户端设置页复制
- 我的配置：个人偏好与个人级数据源，只作用在你自己的账号上

**导师或管理员可见**

- 导师看板：团队总览、实习生状态、团队产出趋势、全部未处理告警，可手动触发风险检查
- 报告查看：按人按区间看日报、计划与周报
- 配置：在个人配置之外，多出团队级设置与服务端配置两块
- 个人中心：导师额外看到待审批成员，飞书首次登录自动建号的账号在这里审批并定角色

**所有人都可见**

- 个人中心：首字母头像、资料编辑、我的统计、登录设备与退出全部设备

## 数据从哪来

- 代码提交：只读你个人配置里关联的本地仓库，不联网、不需要托管平台账号
- 内部任务系统：我的工作、我的待办、我的工时日志三个端点
- 聊天摘要：只采集你绑定的会话，且只落摘要不落原文

采集到的数据在「我的今日」和「我的报告」里可见，导师能看报告、工作记录与风险告警，
但看不到你的聊天摘要。

## 需要配置什么

个人配置（点开卡片修改，保存即生效）

- 个人信息：显示名、飞书用户标识，后者用于私发推送
- 代码提交：提交作者标识与关联的本地仓库路径
- 内部任务系统：个人账号与密码，留空则使用服务账号
- 消息与推送：早晚推送时间、静默时段、告警接收与推送渠道
- 报告偏好：日报详略、是否附提交短哈希、计划重点条数、周报开关与时间
- 风险偏好：关注的提醒类型与等级下限
- 学习偏好：关注的知识分类与标签、作答详细程度

团队级与服务端配置（只有导师能改）

- 团队级设置：风险阈值、默认推送时间、知识目录与检索条数
- 服务端配置：飞书应用、聊天授权与登录两个回调地址、内部系统站点、git 兜底仓库、联网搜索密钥

## 常见问题

**推送收不到**
检查个人配置里的飞书用户标识是否已填，推送渠道是否是「私发给我」或「两者都发」，
以及当前时间是否落在静默时段。

**日报是空的**
先看「我的今日」有没有工作记录。没有记录时不会调用模型，直接生成一条空日报。
没有记录通常是仓库路径或作者标识没配对，或者当天确实没有提交与工时。

**问答说没有找到依据**
说明知识库没有覆盖这个问题。可以换更短的关键词再问，或者把相关资料上传到文档库，
上传后立即可检索。

**怎么切换角色**
角色由导师在个人中心审批并指定，个人不能自己改。飞书首次登录自动建号的账号默认是实习生。

## 界面口令对照

- 「同步知识目录」：按文件重新扫描知识库元数据，只有导师可见
- 「重新检查风险」：立刻跑一遍风险规则，只有导师可见
- 「重新生成」：仅对最后一条答复生效，会先回退这一轮再重跑
- 「退出全部设备」：所有设备上的登录立即失效，包括当前这台
