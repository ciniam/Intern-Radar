## 一句话定位

自动采集实习生的真实工作数据，生成进展报告，主动识别卡点，
并把导师的经验沉淀成可检索的知识。

## 分层结构

| 层 | 职责 | 说明 |
| --- | --- | --- |
| 接入层 | 接口与前端 | 报告、风险、导师视图、学习问答 |
| 应用层 | 业务编排 | 采集、报告、风险、推送、学习、导师视图 |
| 智能体层 | 与模型交互 | 报告生成走单步结构化输出，学习问答走工具调用 |
| 能力层 | 工具与检索 | 工具按需调用，文档检索不走向量库 |
| 数据采集层 | 各数据源适配器 | 代码提交、内部系统任务、聊天摘要 |

## 关键设计取舍

1. 不做向量检索。语料规模只有几十到几百篇，关键词加标签加目录足以定位，
   而且向量化会反向绑定模型厂商。
2. 采集结果先落库，不直接进模型。这样报告可复现、可重试、可审计。
3. 规则先行，模型兜底。风险识别里确定性规则负责精确率，模型负责召回率。
4. 知识文档以文件为唯一事实来源，库里只存元数据，正文按需读取。

## 模块位置

业务代码在独立包下，按功能分子包：采集适配器、服务、智能体、工具、推送、控制器、定时任务。
基线代码保持不动，只在启动类里显式声明扫描范围。

## 工作记录类型

| 类型 | 含义 |
| --- | --- |
| COMMIT | 代码提交 |
| TASK | 内部系统任务 |
| DOC | 文档 |
| MEETING | 会议 |
