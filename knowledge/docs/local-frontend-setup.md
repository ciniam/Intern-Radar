## 依赖要求

Node 16 以上，建议 18 或 20。npm 随 Node 一起安装。

## 启动步骤

1. 进入前端目录，执行安装依赖，网络慢时加国内镜像参数。
2. 执行开发启动命令。
3. 浏览器访问开发地址，页面能正常渲染即完成。

## 常见问题

### 提示脚本被系统禁止运行

这是执行策略拦截了 npm 的 PowerShell 包装脚本。
最简单的处理是改用带 .cmd 后缀的命令，或者把执行策略放开为 RemoteSigned。

### 安装依赖报权限错误

多半是缓存目录权限问题或被占着。
先清理缓存再重装，或改用国内镜像源。

### 页面能开但接口全部失败

开发环境的接口地址写在接口封装文件里，已经指向本地后端。
如果后端换过端口，需要同步改这个地址；后端已经配了跨域，不需要再配代理。

## 与后端联调注意

1. 后端上下文路径带前缀，写请求路径时不要重复拼。
2. 聊天类接口用流式返回，前端用 EventSource 接收，注意跨域下不要带自定义请求头。
3. 页面里所有文案用中文，日志与提示不要中英混排。
