## 鉴权方式

走会话鉴权，不是令牌鉴权。流程是：先取会话标识，再提交账号密码换取登录态，
后续请求都带上这个会话。

## 安全闸门

1. 默认禁止提交登录，必须显式开启才允许。
2. 连续失败达到阈值立即停止，并输出明确告警，避免账号被锁。
3. 会话在有效期内复用，不要每次请求都重新登录。

## 接口返回的陷阱

会话失效时，接口不会返回鉴权错误，而是以成功的状态返回登录页内容。
如果不识别登录页特征，采集结果会是零条，而且日志里看不出任何异常。

处理方式：响应内容里出现登录页特征就直接判定会话失效并抛出明确异常，
不要当成业务成功继续往下走。

## 任务字段说明

1. 任务没有百分比进度字段，只有预估工时、已耗工时与剩余工时。
2. 进度需要按工时折算，折算不出来时不要下结论，交给别的规则判断。
3. 任务状态区分未开始与进行中，停滞判定只能用在已开始的任务上。
4. 同一任务会有多条快照记录，按业务编号取最新一条，否则会把快照当成不同任务。

## 常用端点

任务系统一般提供我的工作、我的待办、我的工时日志三类端点，够支撑采集即可。
任务与缺陷类端点通常需要额外权限，未授权时会返回权限拒绝页。

## 验证顺序

先用不带凭据的探测请求确认接口世代与可用前缀，
再确认账号密码正确后提交登录，避免反复失败导致锁号。
